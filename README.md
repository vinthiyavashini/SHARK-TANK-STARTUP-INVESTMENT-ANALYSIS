# 🚀 Shark Tank Startup Investment Analysis

## 📌 Project Overview
This project analyzes startup investment trends using Shark Tank startup data to understand funding patterns, investor behavior, and business growth insights through data analysis and predictive modeling.

The project focuses on:
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Linear Regression Modeling
- Tableau Dashboard Visualization

## 🎯 Objectives
- Analyze startup investment trends
- Identify factors influencing startup valuation and funding
- Understand investor decision-making patterns
- Predict investment-related outcomes using Linear Regression
- Create interactive business dashboards using Tableau

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Tableau

## 📊 Key Features
- Startup funding trend analysis
- Investor-wise insights
- Industry/category-based analysis
- Data preprocessing & visualization
- Linear Regression model implementation
- Interactive Tableau dashboard
- Business insight generation

## 🤖 Machine Learning Model
### Linear Regression
Used for predictive analysis and identifying relationships between startup investment variables.

## 📈 Tableau Dashboard
The Tableau dashboard includes:
- Investment trend visualization
- Startup category analysis
- Investor participation insights
- Funding distribution analysis
- Business performance metrics
